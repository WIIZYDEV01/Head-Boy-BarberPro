# Head Boy BarberPro

Production-oriented multi-salon barbing salon management software built with Next.js, TypeScript, Tailwind CSS, Supabase, and Paystack.

Owners manage isolated salons. Customers book published salons. Dashboards read real database records and stay empty until you create them.

See [docs/SETUP.md](docs/SETUP.md) for Supabase, Google OAuth, Paystack, and Vercel configuration.

```bash
npm install
npm test
npm run lint
npm run build
npm run dev
```
